# Website Bán Giày

Website bán giày gồm 2 phần chính: **Frontend (ReactJS)** và **Backend (NodeJS + MongoDB)**.

## Cấu trúc thư mục
- `/Frontend`: Giao diện người dùng, viết bằng React.
- `/Backend`: Xử lý API và kết nối cơ sở dữ liệu.

## Chức năng chính
- Đăng ký / Đăng nhập
- Danh sách sản phẩm
- Giỏ hàng
- Quản lý đơn hàng
- Tìm kiếm, lọc theo thương hiệu

## Công nghệ sử dụng
- **Frontend**: ReactJS, Tailwind CSS
- **Backend**: NodeJS, ExpressJS, MongoDB
- **Khác**: JWT Auth, Mongoose, REST API

## Giao diện website bán giày
Link hình ảnh giao diện sản phẩm : https://drive.google.com/drive/u/0/folders/1vgjBHD3ctxu72FIrj8BRKa7fnR7yzDM9

## Frontend
```bash
cd Frontend
npm install
npm run dev
```
## Backend
```bash
cd Backend
npm install
npm start
```
